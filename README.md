# Viza Click

Site institucional da **Viza Click**, agência de inteligência artificial que implementa agentes de IA, automações e presença digital para negócios venderem todos os dias — inclusive fora do horário comercial.

🔗 [viza.click](https://viza.click)

## Destaques técnicos

- Hero 3D interativo construído com **Three.js**, sem framework de build — módulos carregados via `importmap` direto no navegador.
- Animações de scroll, cursor customizado e microinterações escritas em JavaScript puro.
- CSS moderno (grid, custom properties, animações) sem dependência de frameworks CSS.
- Zero dependências de build: `index.html`, `style.css`, `script.js` e `hero.js` rodam direto, sem etapa de compilação.

## Stack

`HTML5` · `CSS3` · `JavaScript` · `Three.js`
